24/7 scanning across top 28 perpetual futures contracts. Computes HMAC SHA-256 signatures, manages 10x isolated leverage, and enforces 0.05% taker fees.

HMAC Signing LogicPython
def delta_request(method, path, api_key, api_secret, payload=""):
    timestamp = str(int(time.time()))
    signature_data = method + timestamp + path + payload
    signature = hmac.new(api_secret.encode(), signature_data.encode(), hashlib.sha256).hexdigest()
    headers = {'api-key': api_key, 'timestamp': timestamp, 'signature': signature}
    return requests.request(method, "https://api.india.delta.exchange" + path, headers=headers, data=payload)

04 External API Integrations

Dhan HQ OpenAPI v2

REST & Market Feed

Direct integration with Dhan broker infrastructure for Indian equity and derivatives. Provides sub-second execution for multi-leg option spreads.

  • Exchange Segments: NSE_EQ, NSE_FNO, BSE_FNO (SENSEX), MCX_COMM.

Delta Exchange India

Crypto Perpetual Futures

FIU-compliant cryptocurrency perpetual contracts settled in INR and USDT with up to 10x leverage.

  • Endpoint: https://api.india.delta.exchange
  • Order Types: Market orders with native Stop-Loss & Take-Profit brackets.
  • Fee Structure: 0.05% Taker Fee on notional position + 18% GST modeled in real-time.

Telegram Bot API

Two-Way Remote Terminal

Delivers signal alerts with rich formatting and inline callback buttons directly to the trader's mobile device.

  • Protocol: Long Polling with offset tracking (zero webhook ingress required).
  • Action Buttons: [ 🚀 Execute Live ], [ 🚫 Ignore ], [ ❌ Square Off ].
  • Security: Restricts order placement to authorized TELEGRAM_CHAT_ID.

10 Algorithmic Strategies Reference

Production Core EMA(5/15) + Williams %R(70)

The primary momentum strategy powering live scanner sweeps across Indian equities and crypto futures.

BUY Entry: EMA(5) > EMA(15) AND Williams %R ≥ -80 (Bullish Momentum)

SELL Entry: EMA(5) < EMA(15) AND Williams %R ≤ -20 (Bearish Momentum)

Target: 80% decay in net option credit (or +4% crypto price)

Stop Loss: 100% expansion of credit received (or -3% crypto price)

Options Structure Defined-Risk Credit Spreads

Eliminates naked tail risk by combining a short option strike with an out-of-the-money hedge.

Bull Put Spread: Sell OTM Put (Leg 1) + Buy Further OTM Put (Leg 2)

Bear Call Spread: Sell OTM Call (Leg 1) + Buy Further OTM Call (Leg 2)

Max Profit: Net Credit Received upfront

Max Risk: Strike Width - Net Credit Received

Mean Reversion RSI_MR Strategy

Captures explosive mean-reverting snapbacks in range-bound or consolidating market regimes.

BUY Entry: 14-period RSI drops below 30 and hooks upward

SELL Entry: 14-period RSI surges above 70 and rolls over

Exit: RSI crosses the neutral 50-median line

Volatility Expansion BB_BREAKOUT Model

Capitalizes on volatility expansions following quiet periods of low-volatility price squeezes.

BUY Entry: Close breaks above 20-period Upper Bollinger Band (2.0 Std Dev)

SELL Entry: Close pierces below 20-period Lower Bollinger Band

Exit: Trailing stop or reversion to the 20 SMA midline
